# Exit Policy

Use a layered exit policy:

- **Thesis stop:** core investment assumption is falsified; prioritize exit.
- **Fundamental stop:** durable value falls or accounting/governance risk rises.
- **Risk stop:** position, sector, liquidity, or drawdown exceeds mandate.
- **Price stop:** user threshold is breached; default action is review, not
  mechanical sale, when intrinsic value is unchanged.
- **Valuation take-profit:** price approaches or exceeds the value range;
  reduce in stages.
- **Allocation take-profit:** appreciation makes the position too large;
  rebalance even if the thesis remains intact.

Show the trigger, evidence, current and target weights, and proposed action.
Never describe a fixed percentage as a guarantee of loss control or profit.
